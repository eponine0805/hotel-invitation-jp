# 実用日本語研究室 — 応用対話・夜間課程

デート終盤での「ホテルへの誘い」という、きわめて限定的な日本語の運用を、**10章・200問**の構成で扱う会話学習アプリです。見た目も講義内容も落ち着いた教材として設計し、テーマの限定性と分析の細かさ自体をユーモアとしています。架空の教育課程で、公的な資格とは無関係です。

## 内容

- 講義10章 × 4節。場面別の例文60件、章別20問×10章の計200問
- 選択肢で進行が変わる会話シミュレーション6件
- 検索できる日本語表現集25件と音声読み上げ
- 間違えた問題の再履修、章ごとの到達度、ローカル保存
- 成人同士で自由に判断できる状況のみを対象とし、同意や拒否を尊重する内容

## Netlify 公開

GitHubリポジトリをNetlifyに接続すればデプロイできます。ビルドコマンドと公開ディレクトリは `netlify.toml` の設定を使用します。Node.jsによる静的ファイルのコピーのみで、外部API・APIキー・サーバーは不要です。

ローカルで確認する場合：

```bash
node --check app.js
node --check content.js
python3 -m http.server 8080
```

## 補足

- 実際の対人関係での結果を保証するものではありません。
- 音声はWeb Speech APIを利用し、端末の日本語読み上げ機能に依存します。
- 進捗は `localStorage` のみ。アカウント・決済・外部APIは使いません。


## 実地演習 3.0

- 16ケース・160の本編判断場面（従来6ケース・約17判断場面から増量）。
- 各場面には3つの発言案と相手の反応を収録。誤答後は会話修復のやり取りが入り、原則として続行します。強い圧力を重ねた場合は相手の意思で途中終了します。
- 100点満点の総合評価と5軸別の成績、改善のためのフィードバック。
- 回答時にページ先頭へ戻る挙動を修正。会話履歴を保持したまま末尾に発言を追加します。
- 中断データ・最高点・受講回数は端末内に保存。外部API・データ送信なし。
- 採点は宿泊への同意を得たかどうかではなく、明確さ・自由な意思決定・配慮を基準にします。

新規シナリオは `simulations-v3.js` に収録。フランス語アプリ等の他のリポジトリには影響しません。
