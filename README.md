# 実用日本語研究室 — 夜間対話学・実践課程

ガチの大学講座に見せかけて「ホテルの自然な誘い方」を過剰に学問する**パロディ学習アプリ**です。「Français Grammaire」の *講義→例文→20問テスト→復習* に着想を得た完全独立の日本語会話練習アプリです。元のリポジトリ・教材・アセットのコピーではありません。

## コンセプト

真面目な見た目／存在しない研究科／架空の単位認定／教授の妙な注釈／珍妙な誤答。**ただし双方が成人で、自由な意思を尊重することは一貫して本気です。**

## 機能

- 詳細講義10章 × 4節、場面別の具体例60件
- 章別20問（知識8問、適切な返答6問、理由6問）＝全200問＋全章ミックス20問
- 選択肢で会話が変わるシミュレーション6本
- フレーズ集25件：検索、カテゴリ絞り込み、コピー、日本語読み上げ
- 返答・解答後の文章を音声で聴ける（Web Speech API、日本語対応端末が必要）
- 間違い問題の復習、80%以上で章修了、記録のローカル保存
- Netlifyのみで公開できるHTML/CSS/JavaScriptの静的サイト。外部API・APIキー・ビルド・アカウント不要
- HTTPSサイトでのPWAインストールとオフラインキャッシュ（初回オンライン接続が必要）

## Netlifyへの公開

### GitHubから自動公開

1. GitHubで新規リポジトリ `hotel-invitation-jp` を作り、**このフォルダの中身**をリポジトリ直下にアップロード。
2. Netlify → Add new project → Import an existing project → GitHub → 作ったリポジトリを選ぶ。
3. Build command は空欄、Publish directory は `.`（netlify.tomlでも定義済み）。Deployを選ぶ。
4. GitHubへ変更をコミットすると、Netlifyで自動再公開される。

### GitHubを使わず手動公開

Netlifyの手動デプロイ画面で、このフォルダの内容をデプロイ（ZIPファイルを解凍してから、フォルダをドラッグ＆ドロップする方法が確実）。公開ルートはこのフォルダ直下です。

## 確認方法

```bash
node --check app.js
node --check content.js
python3 -m http.server 8080
# http://localhost:8080
```

## 注意

- 双方が成人で自由な意思で判断できる場面のみを対象にしています。
- 相手の好意や態度から性的同意を推定しない、相手が断ったら引く、飲酒・疲労・力関係を利用しない、という原則を取り入れています。
- 音声の品質と再生可否はブラウザや端末に依存します。日本語音声エンジンのない端末では使用できません。
- 進捗は `localStorage` に保存され、端末間同期はありません。
- データ送信・広告・アクセス解析・決済はありません。
