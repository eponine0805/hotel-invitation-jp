# 実用日本語研究室 — 夜間対話学・実践課程

**真面目な語学学習アプリの皮を被った、全力の教育系パロディ。**

ホテルへの自然な誘い方を「研究室」「架空の単位」「教授の注釈」「単位認定試験」で、なぜか本格的に学ぶWebアプリです。双方が成人で、相手の自由な意思を尊重することは一貫して守ります。

## 教材と機能

- 10講義 × 4節の詳細解説
- 60件の会話例と実践不可の珍妙な誤答
- 講義8問＋場面演習12問 × 10講義 = 200問
- 6つの模擬会話、フレーズ集、音声読み上げ、復習
- ローカル保存、API不要・サーバーレス、Netlify専用

## Netlify

静的HTML/CSS/JavaScript構成です。配布された `hotel-invitation-jp-source-v2.zip` の中身を本リポジトリの直下に配置してください。

Netlifyで **Import an existing project → GitHub → このリポジトリ** を選択します。Build commandは空欄、Publish directoryは `.` です。

## このプロジェクトの立ち位置

研究室・教授・単位・検定・学説はすべてジョークです。実在する大学や資格機関とは関係ありません。
